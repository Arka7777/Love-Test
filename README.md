# Love Quiz ❤️
Edit `src/config.js` (names, message, questions, button text).
    npm install && npm run dev      # http://localhost:5173
    npm run build && npm run preview
Deploy: push to GitHub, import on vercel.com (Framework: Vite, build `npm run build`, output `dist`). No extra config needed.
